# 可以直接复制的说法

**[English](prompts.en.md)** | 简体中文

agent 会自动选工具、补参数。你只需要说清楚**环境 + 对象 + 想知道的结论**。
下面的问法都验证过，比「查一下元数据」这种说法有效得多。

---

## 先看环境

```
四个环境都连一下，看看各自在干什么。
```

```
SIT 现在有正在跑的导入或发布吗？我想改点元数据。
```

```
昨天到现在有哪些后台作业失败了？
```

## 查元数据

```
account 上有哪些自定义字段？只列 contoso_ 开头的。
```

```
列出最近安装的 10 个解决方案，带版本和受管状态。
```

```
Account 主表单加载了哪些脚本？每个脚本绑了哪些事件？
```

```
有哪些业务规则作用在 opportunity 上？
```

## 查层（为什么这个环境是这样）

```
account 这个实体在四个环境里分别有哪几层？当前生效的是哪个解决方案？
```

```
account.name 这个字段被哪些解决方案覆盖过？
```

```
为什么 SIT 的 Account 表单和 DEV 不一样？是谁盖的？
```

## 影响面（改/删之前）

```
contoso_customertier 这个字段被哪些表单、视图、流程用到？DEV 和 SIT 都看。
```

```
contoso_/scripts/account_form.js 这个脚本被哪些表单引用？
```

```
Contoso.Customizations 这个程序集注册了多少类型、多少步骤？版本多少？
```

```
contoso_taxcategory 这个选项集里，每个值各有多少条客户记录在用？
```

## 快照与对比

```
把 DEV 和 SIT 的表单、视图、字段同步一份，然后告诉我差异。
```

```
DEV 今天的元数据和上一份快照比，多了什么？
```

```
SIT 和 UAT 的插件步骤有什么不同？
```

## 发布评估

```
ContosoBase 从 DEV 发到 SIT 和 UAT，有什么风险？
```

```
这个解决方案导入后，会压掉哪些别的解决方案？
```

```
目标环境缺这个解决方案时，导入会发生什么？
```

## 代码检查

```
这个 MR 发到 UAT 会不会跑不起来？https://gitlab.example.com/.../merge_requests/7759/diffs
```

```
这个 MR 改的表单脚本，读的字段在目标环境的表单上都有吗？
```

```
这个 MR 动了 C# 插件，目标环境的程序集、类型、步骤、镜像都齐吗？
```

## 契约与漂移

```
DEV 的插件注册，SIT 和 UAT 都跟上了吗？
```

```
表单引用的 Web 资源有没有在下游环境缺失？
```

```
这条差异是已知的，登记成豁免，30 天。
```

```
和上次比，漂移是变多还是变少了？
```

## 写入

```
给 contoso_taxcategoryos 加这几个选项：AD3|Andorra: Tax Register Number（先只出计划，别执行）
```

```
在 account 上加一个文本字段 contoso_CustomerTier，120 字符，显示名「客户等级」。
```

```
把 account.name 的显示名改成「客户名称」。
```

```
执行 mw04aul6-1ci6aa
```

```
这个计划先取消。
```

写入的通用句式：**先说要改什么 → 确认「只出计划」→ 看过列表再说「执行 <planId>」**。
把两句话合成一句时，agent 也会先生成计划、再弹确认卡片，不会直接写。

## 业务数据

```
contoso_systemconfiguration 里有多少条记录？按 contoso_containsecret 分组看看。
```

```
取 5 条 contoso_systemconfiguration 看下样例，字段只要 contoso_key 和 contoso_value。
```

```
帮我在 contoso_systemconfiguration 里补一条：contoso_key = FEATURE_X，contoso_value = 1。
```

（最后一条需要 `data.write` 授权，会弹确认卡片。）

## 运维

```
.d365 现在占多大？哪些能清？
```

```
把查询留证按策略清理一下，先预演，不要真删。
```

```
快照压一下，太占地方了。
```

## 说话的小技巧

| 想更准 | 这样说 |
| --- | --- |
| 限定环境 | 「在 SIT」「四个环境都看」 |
| 限定范围 | 「只要 contoso_ 开头的」「只看主表单」 |
| 要结论不要清单 | 「告诉我能不能删」「给我一句结论」 |
| 要证据 | 「列出具体是哪几张表单」 |
| 写入前 | 「先只出计划」「不要执行」 |
| 大范围操作 | 「先评估，别动环境」 |

反过来，避免这些说法——它们会让 agent 猜：

- 「查一下元数据」（查哪类？哪个环境？）
- 「看看有没有问题」（什么问题？发布、引用、还是契约？）
- 「改一下这个字段」（改成什么？）
